# Available Maps

Reference table mapping each in-game **map ID** to its **friendly name**. Map IDs appear in room data (e.g. `ROUND{n}_MAP_ID` in [Get Room](/in-game/get-room)); use this table to resolve them to a human-readable name.

Rows where **Name** is `—` have no distinct friendly name — for those, the API returns the **map ID itself** as `ROUND{n}_MAP_NAME`.

> See also: [Get Room](/in-game/get-room) | [Live Game Stats](/in-game/live-game)

## Notes

- Map IDs are case-insensitive when matched.
- Rows with `—` in the **Name** column have no distinct friendly name; for those the API returns the map ID itself as the round map name.
- User-generated (UGC) maps are not listed here. When a round runs a UGC map, the room data carries its share/link properties instead.
